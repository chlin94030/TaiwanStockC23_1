# Alpha Radar V23.1｜Benchmark-First 全功能整合研究版

**執行入口：`app.py`｜開發版本：23.1.0-benchmark-first｜研究用途，不會自動下單**

## 一次部署後的使用方式

1. **保留目前既有 `data/` 資料夾。** 如果 Streamlit Cloud 的本機資料已遺失，先切到「資料準備與備份」，用自己保存的 `V21_DATABASE.zip` 還原；不要為了試新版重新跑全市場數據。
2. 將此 ZIP **解壓後的檔案**，一次上傳並覆蓋至**原 GitHub repository 的根目錄**，Commit 到現有部署的 branch。**不要把 ZIP 直接上傳 GitHub，也不要另建子資料夾。** `app.py` 是正式入口，沒有 `v231_app.py`、沒有其他 App 要再選。
3. 開啟原本的 Streamlit 網址；切換到「**V23.1全新選股驗效**」。首次部署如仍顯示 V22 舊模式，可至 Manage app > Reboot app **一次**。下一次只改策略 JSON 不需 Reboot。
4. 在 V23.1 頁按「**▶ 沿用現有行情，開始／接續V23.1驗效**」；系統先以純價格控制組和 0050 建立完整每日淨值比較。無需提供基本面資料就可做這項研究對照，但完整基本面模型會顯示 coverage blocked。
5. 完整基本面模型需有**歷史逐公司公告時點**。透過同頁的「新增資料」下載三種 CSV 範本，再匯入。也可先下載公開 MOPS 歷史月營收作**研究性代理資料**（不能當正式公告時點）。匯入完成後按同一顆驗效按鈕；已有 V22 資料與特徵快取不會重抓。
6. 完成後在同頁下載 `V23_1_VALIDATION.zip` 或 `V23_1_VALIDATION.xlsx`，傳回 ChatGPT 分析。之後升級策略只要上傳單一 `strategy_release_Rxxx.json`，**不再替換 Python 檔案**。

手機操作重點：**正常只有『V23.1全新選股驗效』→『開始／接續』→『下載報告』三個動作**。需要基本面研究時才展開資料匯入。

## 新增功能（保留所有 V22.4.2 功能）

- `v231_data.py`：月營收、EPS、毛利率、法人訊號的標準化 CSV 匯入；逐筆公告時間與修訂版本稽核；官方即時快照只能從下載時刻開始有效。
- `v231_mops.py` / `v231_mops_jobs.py`：MOPS 上市／上櫃歷史月營收可接續下載，彙整表缺少**各公司真實公告時點**，一律保守標註 `PROXY`，正式認可不通過。
- `v231_factors.py`：營收 YoY／成長加速度、EPS YoY、毛利率改善、法人流向、120日相對0050強度；T 日 15:00 前已公布才能用於 T+1。
- `v231_engine.py`：0050唯一基準；價格相對強度控制組；40／35／15／10 基本面融合候選；無法人消融組。20日與60日為主要研究週期，5日作輔助。市場階段及產業集中度限制；沒有個股曝險的資產持有0050而不是現金。
- `v231_runner.py`：鎖定 KOSTO250、月末T決策、T+1開盤進場、按持有期結算、跨月持有不重複投入資金、逐日淨值、買賣成本及額外成本壓力比較、6個月滾動區塊診斷；獨立24個月的最後保留期不打開。
- `v231_release.py`：帶 `requires_engine`、模型因子與 SHA 的單一策略 JSON，錯誤格式直接阻止，改版自動失效舊策略驗效快取。
- `v231_ui.py`：行動裝置優先的一鍵驗效頁、報告下載、一鍵部署自檢。保留原 V22.4.2 工作頁、原 V22/資料準備功能。
- `lab_snapshot.py`：既有 V21_DATABASE 備份格式向下相容，並包含 V23 報告、公告資料、公開歷史營收代理快取與策略 JSON。**務必定期下載備份**。

## 何謂真正通過 0050？

目前 **沒有**。V23.1 明確區分「研究回顧」與「可投資驗收」。正式門檻規定至少年化淨超額 0050 **+5 個百分點**、IR ≥ 0.5、額外交易成本壓力下仍達標、回撤不比 0050 多逾10百分點、足夠多獨立樣本、基本面公告時點與歷史成分名冊經獨立稽核、以及真正未看過的前瞻資料。只要任一證據缺口未解決，`official_acceptance` 固定標註**NOT_AUTHORIZED_CURRENT_SNAPSHOT_AND_EXPOSED_HISTORY**。本版不會假裝完成這些條件。

**現有資料重要限制：** 因既有股票名冊可能是今天仍掛牌的名單，容易產生存活者偏差；現有 yfinance 歷史調整價也非保留每次價格修訂時間的原始版本；既有2021–2026資料已有大量研究回顧，不能再當成獨立最終樣本外。

## 執行環境與完整性

- Python 3.13 / 3.14，`streamlit run app.py`，相依項目見 `requirements.txt`。
- 嚴禁將登入 Token / 私密憑證放入 GitHub；需要時用 Streamlit secrets。
- 不自動下單；不連結券商帳戶；不向外保證收益。
- 結果儲存在 `data/v21_universe_lab/v23/`，**Streamlit Cloud 本機磁碟可能因重新啟動而遺失**，務必從備份頁下載 `V21_DATABASE.zip`。
- 可在本機對既有資料直接執行 `python run_v231.py --root data/v21_universe_lab`。
- 工程離線自檢：`python -m pytest -q tests`；預設測試使用人工合成資料，**不是實際台股超額績效回測**。

詳細資料欄位／時間處理見 `V23_1_DATA_FORMATS.md`；測試清單與限制見 `V23_1_QA_REPORT.md`。
